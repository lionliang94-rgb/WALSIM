## ✨ 项目介绍

这是一个面向《边狱巴士（Limbus Company）》玩家制作的非官方辅助工具，主要用于规划瓦尔普吉斯之夜（Walpurgis Night）的碎片兑换。

通过录入当前账号的罪人碎片库存、选择想要兑换的人格和 E.G.O，工具会自动计算实际碎片缺口以及需要消耗的自选碎片箱数量。

本项目纯ai制作，除了这行字以外都是ai生成的。

无需登录，无需注册，[打开网页](https://walsim.vercel.app) 或[这个网页](https://lionliang94-rgb.github.io/WALSIM/)即可使用。

## 🎯 核心功能

### 1. 瓦夜兑换数据库

- 收录第 1 期至第 9 期瓦夜的可兑换人格与 E.G.O。
- 按瓦夜期数、人格及 E.G.O 分类浏览。
- 提供卡牌立绘预览。
- 支持查看和调整卡牌强度评级（T0 / T0.5 / T1 / T1.5 / T2 / T3）。
- 支持自定义添加兑换项目。

### 2. 碎片库存管理

- 分别管理 12 位罪人的碎片数量。
- 录入当前账号已有碎片库存。
- 支持标记已经拥有的人格或 E.G.O。
- 自动排除已经拥有的项目，避免重复计算。

### 3. 智能兑换计算

- 自由勾选计划兑换的人格与 E.G.O。
- 自动按照罪人分类统计碎片需求。
- 自动抵扣对应罪人已有的碎片。
- 计算最终碎片缺口。
- 根据自选碎片箱的预期收益，计算需要准备的箱子数量。
- 提供各罪人碎片消耗明细。

**计算原则：**

每位罪人的碎片独立计算，不能跨罪人抵扣。

默认按照每个自选碎片箱期望获得 2 个碎片进行估算，也支持调整箱子折算参数。

### 4. 兑换规划与导出

- 支持预设兑换方案。
- 支持按照人格、E.G.O 和评级筛选。
- 自动生成兑换规划汇总。
- 支持导出高清兑换规划长图。
- 方便保存规划或分享给其他玩家。

### 5. 本地数据保存

- 使用浏览器 LocalStorage 保存自定义数据。
- 刷新页面后保留个人规划。
- 无需注册账号。
- 数据默认保存在当前浏览器及设备中。

## 🚀 使用方法

1. 打开计算器。
2. 录入 12 位罪人的当前碎片数量。
3. 输入自己拥有的自选碎片箱数量。
4. 在瓦夜数据库中选择想要兑换的人格和 E.G.O。
5. 对已经拥有的卡牌进行标记。
6. 查看自动生成的碎片需求、抵扣情况及最终箱子需求。
7. 导出兑换规划长图，保存自己的兑换计划。

## 💻 本地运行

**环境要求：** Node.js

克隆项目：

```bash
git clone <你的GitHub仓库地址>
cd limbus-walpurgis-calculator
```

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

执行生产构建：

```bash
npm run build
```

构建完成后，生成的文件位于 `dist` 目录。
